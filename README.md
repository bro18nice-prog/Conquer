# Conquer

A territory game for walks and runs, built with React Native and Expo. Record a route, close a loop, and compete for territory with a private group.

## Features

- GPS activity tracking and route validation.
- Territory geometry, progression, and activity history.
- Local storage with backup import and export.
- A separate demo mode using simulated activities.
- Optional Supabase authentication and group synchronization.

## Run locally

Install a Node.js version supported by the Expo version in `package.json`:

```sh
npm ci
npm run web
```

Use `npm run android` for a native Android development build. Background GPS requires device testing and permissions; a browser demo does not validate background tracking. iOS builds require macOS and Xcode.

## Optional backend

Copy `.env.example` to `.env` and set your own Supabase project URL and public anonymous key. Review and apply `supabase/schema.sql` in your own project. Never embed a service-role key in the app. Without backend configuration, cloud synchronization is unavailable.

## Checks

```sh
npm run typecheck
npm test
npm run build:web
```

## Project layout

| Path | Purpose |
| --- | --- |
| `App.tsx` | App screens and navigation |
| `src/core.ts`, `src/geometry.ts` | Activity validation and territory rules |
| `src/tracking.ts` | Location tracking |
| `src/storage.ts`, `src/repository.ts` | Local persistence |
| `src/cloud.ts`, `supabase/schema.sql` | Group backend |
| `src/Map*` | Native and browser maps |
| `tests` | Rules, persistence, and backend tests |

`src/mapHtml.ts` is generated by `npm run build:map`; change the generator when changing the embedded map. Release builds use your own signing environment variables; signing keys are not part of this repository.

Prototype under development. GPS accuracy, battery use, and background behavior need validation on physical devices. See [release notes](RELEASE-NOTES.md) for the existing development history.
